# Geist

`Geist-Variable.woff2` is the unmodified variable Geist font from [Vercel's official font repository](https://github.com/vercel/geist-font/blob/main/fonts/Geist/webfonts/Geist%5Bwght%5D.woff2), retrieved on 2026-10-21.

The included `OFL.txt` preserves the SIL Open Font License. Next.js loads this file through `next/font/local`; production builds and browsers do not need a third-party font service.
